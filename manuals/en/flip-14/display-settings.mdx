## Display Configuration — Windows

**Want to extend your workspace?**

Go to Display Settings and choose 'Extend desktop to this display'. Use the 'Identify' button to see which screen has which number, then drag the screens into the correct order.

**Screen upside down?**

Select the relevant screen, go to 'Display orientation' and choose 'Flipped' to correct it.

**Need more overview?**

Click 'Scale' and set it to 150% for a larger display of text and elements.

**Working with three screens?**

Use the settings of your graphics card to synchronize the screens.

## Display Configuration — macOS

1. Open System Settings.
2. Go to Displays.
3. Click on Arrangement, as shown in image 1.
4. Arrange the displays in the desired order, as shown in image 2.
