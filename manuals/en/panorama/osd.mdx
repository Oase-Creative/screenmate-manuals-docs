## Per-Screen Settings

The Screenmate Panorama offers independent settings per screen. Follow the steps below to configure each display.

### Opening the OSD Menu

- Press the **Power button** briefly to open the OSD menu of one screen.
- Press the Power button briefly again to switch to the next screen.
- Use the **+ / −** buttons to navigate the menus.
- Press the **Confirm / Exit** button to select an option.
- Use the **+ / −** buttons again to adjust values.

### Adjusting Brightness

Brightness can be set per screen, from 0 to 100.

- Press the **Down (−)** button to open the brightness menu.
- Press the **Exit** button to close the menu.
- Press the **Down (−)** button again to open the brightness menu for the next screen.
- Adjust the brightness with the **+ / −** buttons.

### Adjusting Volume

Volume control is only available on the left screen (DP monitor).

- Press the **Up (+)** button to open the volume menu.
- Use the **+ / −** buttons to set the volume from 0 to 100.

## Display Configuration (OS-Level)

The Panorama drives three independent screens, so you may want to adjust the desktop layout in your operating system.

### Windows

1. Open **System Settings**.
2. Go to **Display**.
3. Click **Arrange** as shown in image 1.
4. Drag the displays into the desired order as shown in image 2.

**Extend your workspace:** Open Display Settings and choose **"Extend desktop to this display"**. Use the **Identify** button to see which screen has which number, then drag them into the correct order.

**Screen upside down?** Select the affected screen, go to **Display orientation**, and choose **"Flipped"** to correct it.

**Need more room?** Click **Scale** and set it to 150% for larger text and UI elements.
