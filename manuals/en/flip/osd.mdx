## Using the OSD Menu

1. Press the **M** (Menu) button to open the OSD menu.
2. Use the **+** and **−** buttons to select the setting you want.
3. Press the **M** (Menu) button to confirm your choice.
4. Hold the **M** (Menu) button to return to the previous page.

<img src="/images/Screenmate%20-%20Flip%2015.6%20-%20Handleiding%20images/osd-backlight.png" alt="OSD Backlight menu" className="rounded-lg border border-gray-200" />

## Backlight

- **Brightness (BRIGHTNESS):** Adjustable from 0 to 100.
- **Contrast (CONTRAST):** Adjustable from 0 to 100.
- **ECO Mode (ECO):** Preset picture modes for different uses (Standard, Game, Movie, Text, FPS, RTS, Energy Saving).
- **DCR (Dynamic Contrast Ratio):** Choose ON or OFF to enable or disable dynamic contrast.
- **Sharpness (SHARPNESS):** Adjustable from 0 to 4.

## Image

<img src="/images/Screenmate%20-%20Flip%2015.6%20-%20Handleiding%20images/osd-image.png" alt="OSD Image menu" className="rounded-lg border border-gray-200" />

- **Aspect Ratio (ASPECT):** Switch the aspect ratio between 4:3 and WIDE.

## Color

<img src="/images/Screenmate%20-%20Flip%2015.6%20-%20Handleiding%20images/osd-color.png" alt="OSD Color menu" className="rounded-lg border border-gray-200" />

- **Color Temperature (COLOR TEMP.):** Manually set the RGB values or pick a preset mode (Warm, Cool, User, Standard).
- **Red (RED):** Adjustable from 0 to 100.
- **Green (GREEN):** Adjustable from 0 to 100.
- **Blue (BLUE):** Adjustable from 0 to 100.

## Settings

<img src="/images/Screenmate%20-%20Flip%2015.6%20-%20Handleiding%20images/osd-set.png" alt="OSD Settings menu" className="rounded-lg border border-gray-200" />

- **Language (LANGUAGE):** Choose the OSD language. Available languages: English, French, German, Simplified Chinese, Italian, Spanish, Portuguese, Turkish, Polish, Dutch, Japanese, Korean.
- **OSD Timer (OSD TIMER):** Set the time after which the settings menu automatically closes (10–60 seconds).
- **Transparency (TRANSPARENCY):** Adjust the transparency of the settings menu.

## Reset

<img src="/images/Screenmate%20-%20Flip%2015.6%20-%20Handleiding%20images/osd-reset.png" alt="OSD Reset menu" className="rounded-lg border border-gray-200" />

- **Reset (RESET):** Choose RESET to return all settings to their factory defaults.
- **HDR Mode (HDR MODE):** Enable HDR (High Dynamic Range) if the device is compatible. Available modes: Off, Auto, 2084.

## Other

<img src="/images/Screenmate%20-%20Flip%2015.6%20-%20Handleiding%20images/osd-other.png" alt="OSD Other menu" className="rounded-lg border border-gray-200" />

- **Source (SOURCE):** Pick from two signal sources: Type-C1 / Type-C2 and HDMI.
- **Low Blue Light (LOW BLUE LIGHT):** Reduces the amount of blue light from the screen to ease eye strain.
