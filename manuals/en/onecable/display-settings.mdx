## Display Configuration Windows

**Want to extend your workspace?**

Go to Display Settings and choose 'Extend desktop to this display'. Use the 'Identify' button to see which screen has which number. Then you can easily drag the screens into the correct order.

**Screen upside down?**

Select the relevant screen, go to 'Display orientation' and choose 'Mirrored' to correct this.

**Need more overview?**

Click on 'Scale' and set it to 150% for a larger display of text and elements.

## Display Configuration MacOS

1. Open System Settings.
2. Go to Displays.
3. Click on Arrangement.
4. Arrange the displays in the desired order.
