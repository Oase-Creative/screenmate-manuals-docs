## Wat is de Screenmate Infinity Lite?

De Screenmate Infinity Lite is een 15,6" Full HD dubbelscherm-uitbreiding die je achter je laptop monteert. Zo krijg je onderweg twee extra draagbare schermen voor meer werkruimte. Aansluiten doe je via USB-C of HDMI en hij is plug-and-play met laptops, telefoons, tablets en spelcomputers.

## Technische specificaties

| Functie | Specificatie |
| :--- | :--- |
| **Resolutie** | 1920×1080 |
| **Helderheid** | 300 cd/m² |
| **Beeldverhouding** | 16:9 |
| **Responstijd** | 10 ms |
| **Grootte** | 15,6" |
| **Contrast ratio** | 1000:1 |
| **Paneeltype** | IPS |
| **Scherm type** | LCD |
| **Kijkhoek** | 178° |

| **Kleurdekking** | 72% NTSC |
| **Backlight** | LED |
| **Gewicht** | 2390 gram |
| **Afmetingen ingeklapt** | 36,1 × 21,6 × 4,5 cm |

<Note>
**Belangrijke informatie:**

Als het scherm geen signaal ontvangt of het signaal instabiel is, sluit dan een externe 5V/2A voedingsadapter aan om je Screenmate van voldoende stroom te voorzien. De vereiste DC-invoer ligt tussen 5V en 20V (met een tolerantie van ±2V).
</Note>
