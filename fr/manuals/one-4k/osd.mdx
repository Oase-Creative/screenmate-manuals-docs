## Commandes et menu OSD

**Allumer&nbsp;:** maintenez le bouton d'alimentation enfoncé pour allumer le moniteur. Le moniteur s'allume également automatiquement lorsque l'alimentation est raccordée.

**Ouvrir le menu OSD&nbsp;:** appuyez sur le bouton d'alimentation pour ouvrir le menu OSD.

**Naviguer&nbsp;:** utilisez le bouton + ou − pour naviguer dans le menu. L'option sélectionnée est surlignée en jaune.

**Sélectionner&nbsp;:** appuyez sur le bouton d'alimentation pour sélectionner une option ou valider un réglage.

**Régler les paramètres&nbsp;:** utilisez le bouton + ou − pour modifier une valeur, puis appuyez sur le bouton d'alimentation pour l'enregistrer.

**Revenir en arrière&nbsp;:** maintenez le bouton − enfoncé pour revenir au menu précédent.

### Raccourcis volume et luminosité

- Appuyez sur le bouton **+** pour régler la luminosité.
- Appuyez sur le bouton **−** pour régler le volume.

### Verrouillage de l'OSD

Si les boutons situés à l'avant ne répondent plus, le menu OSD est peut-être verrouillé. Maintenez le bouton situé au-dessus du bouton d'alimentation enfoncé pendant **10 secondes** pour le déverrouiller.
