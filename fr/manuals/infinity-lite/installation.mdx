## Déplier les écrans

Suivez ces étapes dans l'ordre pour déployer en toute sécurité les deux écrans d'extension derrière votre ordinateur portable.

### 1. Détacher l'écran du support

<Warning>
Dépliez complètement le moniteur afin d'éviter tout dommage.
</Warning>

<img src="/images/Screenmate%20-%20Infinity%20Lite%20-%20Handleiding%20images/install-1-unfold.png" alt="Détacher l'écran du support" className="rounded-lg border border-gray-200" />

### 2. Fixer le support principal

Placez le petit support et utilisez la fixation rotative à 360° pour le mettre en position.

<img src="/images/Screenmate%20-%20Infinity%20Lite%20-%20Handleiding%20images/install-2-main-stand.png" alt="Fixer le support principal" className="rounded-lg border border-gray-200" />

### 3. Monter le support d'écran

<Warning>
Maintenez des deux mains les deux emplacements indiqués par les flèches rouges et tirez l'écran vers l'extérieur pour libérer l'écran unique.
</Warning>

Vous pouvez utiliser l'Infinity Lite avec un support pour écran unique, en position verticale ou en position horizontale.

<img src="/images/Screenmate%20-%20Infinity%20Lite%20-%20Handleiding%20images/install-3-screen-support.png" alt="Monter le support d'écran" className="rounded-lg border border-gray-200" />

### 4. Déployer le cadre

Ouvrez le cadre jusqu'au clic pour le déployer.

<img src="/images/Screenmate%20-%20Infinity%20Lite%20-%20Handleiding%20images/install-4-frame.png" alt="Déployer le cadre" className="rounded-lg border border-gray-200" />

### 5. Régler le support

Le support est doté d'une fixation rotative à 360°.

<Warning>
Ouvrez le support, réglez-le sur le bon angle d'appui, placez-le derrière l'écran de votre ordinateur et terminez l'installation du support d'écran.
</Warning>

<img src="/images/Screenmate%20-%20Infinity%20Lite%20-%20Handleiding%20images/install-5-adjust.png" alt="Régler le support" className="rounded-lg border border-gray-200" />

### 6. Ouvrir les écrans

<Note>
Réglez la distance entre l'écran portable et l'écran de l'ordinateur selon vos préférences pour une meilleure expérience d'utilisation.
</Note>

<img src="/images/Screenmate%20-%20Infinity%20Lite%20-%20Handleiding%20images/install-6-open.png" alt="Ouvrir les écrans" className="rounded-lg border border-gray-200" />

### 7. Fermer les écrans

<Warning>
Respectez le bon ordre lors de l'ouverture et de la fermeture afin d'éviter tout dommage à l'appareil. Rangez votre Screenmate avec soin afin d'éviter d'endommager le matériel.
</Warning>

<img src="/images/Screenmate%20-%20Infinity%20Lite%20-%20Handleiding%20images/install-7-close.png" alt="Fermer les écrans" className="rounded-lg border border-gray-200" />

## Options de connexion

L'Infinity Lite prend en charge deux méthodes de connexion principales, selon les ports de votre ordinateur portable.

### Connecter le Screenmate Infinity Lite à votre ordinateur portable

**Connexion USB-C**

Si votre ordinateur portable dispose d'un port USB-C prenant en charge la vidéo, un seul câble USB-C vers USB-C suffit pour raccorder le produit à votre ordinateur portable. Branchez le câble sur le premier ou le deuxième port du Screenmate, puis raccordez-le au port USB-C de votre ordinateur portable.

<img src="/images/Screenmate%20-%20Infinity%20Lite%20-%20Handleiding%20images/connection-usb-c.png" alt="Connexion USB-C uniquement" className="rounded-lg border border-gray-200" />

**Connexion USB et HDMI**

Si votre ordinateur portable dispose d'un port USB-A ou USB-C **et** d'un port HDMI, utilisez deux câbles&nbsp;:

- Un câble HDMI vers USB-C (pour la vidéo)
- Un câble USB-A ou USB-C vers USB-C (pour l'alimentation)

<Warning>
Branchez le câble HDMI vers USB-C sur le **troisième** port du Screenmate pour le signal vidéo. Branchez le câble USB-A ou USB-C vers USB-C sur le premier ou le deuxième port pour l'alimentation.
</Warning>

<img src="/images/Screenmate%20-%20Infinity%20Lite%20-%20Handleiding%20images/connection-usb-hdmi.png" alt="Connexion USB + HDMI" className="rounded-lg border border-gray-200" />

<Note>
**Important&nbsp;:** si l'écran ne reçoit aucun signal ou si le signal est instable, branchez un adaptateur secteur externe de 5&nbsp;V/2&nbsp;A afin que votre Screenmate dispose d'une puissance suffisante.
</Note>

### Connecter le Screenmate à votre téléphone ou à d'autres appareils

Basculez sur le mode de connexion approprié (alimentation externe requise) pour utiliser le Screenmate avec un téléphone, une console de jeu ou un autre appareil USB-C. Le mode téléphone nécessite lui aussi une alimentation externe.

<img src="/images/Screenmate%20-%20Infinity%20Lite%20-%20Handleiding%20images/connection-phone-console.png" alt="Connexion à un téléphone ou à une console" className="rounded-lg border border-gray-200" />
