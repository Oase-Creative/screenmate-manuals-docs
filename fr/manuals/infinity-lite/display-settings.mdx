## Configuration de l'affichage

### Windows <svg className="inline-block w-5 h-5 -mt-1 ml-2" viewBox="0 0 24 24" fill="currentColor"><path d="M0 3.449L9.75 2.1v9.451H0m10.949-9.602L24 0v11.4H10.949M0 12.6h9.75v9.451L0 20.699M10.949 12.6H24V24l-12.9-1.801"/></svg>

**Vous souhaitez étendre votre espace de travail&nbsp;?**
Allez dans Paramètres d'affichage et choisissez **Étendre le Bureau à cet écran**. Utilisez le bouton **Identifier** pour voir quel écran porte quel numéro. Vous pouvez ensuite faire glisser les écrans dans le bon ordre.

<img src="/images/Screenmate%20-%20Infinity%20Lite%20-%20Handleiding%20images/display-windows.png" alt="Paramètres d'affichage Windows avec le bouton Identifier" className="rounded-lg border border-gray-200" />

**Un écran est à l'envers&nbsp;?**
Sélectionnez l'écran concerné, allez dans **Orientation de l'affichage** et choisissez **Paysage (inversé)** pour corriger cela.

**Besoin d'une meilleure vue d'ensemble&nbsp;?**
Cliquez sur **Échelle** et réglez-la sur **150&nbsp;%** pour un texte et des éléments plus grands.

**Vous travaillez avec trois écrans&nbsp;?**
Organisez les trois écrans dans la vue **Identifier** en faisant glisser chacun d'eux pour qu'il corresponde à sa position physique.

<img src="/images/Screenmate%20-%20Infinity%20Lite%20-%20Handleiding%20images/display-windows-scaling.png" alt="Paramètres Windows d'échelle, de résolution et d'orientation de l'affichage" className="rounded-lg border border-gray-200" />

1. Ouvrez les **Réglages Système**.
2. Allez dans **Moniteurs**.
3. Cliquez sur **Disposition** comme illustré sur l'image&nbsp;1.
4. Faites glisser l'écran du côté souhaité comme illustré sur l'image&nbsp;2.

## Réglages du son

### Windows <svg className="inline-block w-5 h-5 -mt-1 ml-2" viewBox="0 0 24 24" fill="currentColor"><path d="M0 3.449L9.75 2.1v9.451H0m10.949-9.602L24 0v11.4H10.949M0 12.6h9.75v9.451L0 20.699M10.949 12.6H24V24l-12.9-1.801"/></svg>

- Cliquez sur l'icône du haut-parleur en bas à droite de la barre des tâches.

<img src="/images/Screenmate%20-%20Infinity%20Lite%20-%20Handleiding%20images/sound-windows-taskbar.png" alt="Icône de volume dans la barre des tâches Windows" className="rounded-lg border border-gray-200" />

- À droite de la barre de volume, choisissez le périphérique de sortie souhaité.

<img src="/images/Screenmate%20-%20Infinity%20Lite%20-%20Handleiding%20images/sound-windows-flyout.png" alt="Volet de volume Windows" className="rounded-lg border border-gray-200" />

- Vous pouvez régler le volume de chaque application séparément.
- Tout en bas, vous trouverez un raccourci vers les paramètres de son complets.

<img src="/images/Screenmate%20-%20Infinity%20Lite%20-%20Handleiding%20images/sound-windows.png" alt="Paramètres de sortie audio Windows" className="rounded-lg border border-gray-200" />

Sélectionnez le périphérique de sortie **Screenmate** — il apparaît sous le nom **S6-L (HD Audio Driver for Display Audio)** (l'autre écran apparaît sous le nom **S6-R**). Sur la capture d'écran, le **Speaker (Realtek(R) Audio)** mis en évidence est le haut-parleur intégré de votre ordinateur portable, et non le Screenmate — choisissez plutôt **S6-L**.

### macOS <svg className="inline-block w-5 h-5 -mt-1 ml-2" viewBox="0 0 24 24" fill="currentColor"><path d="M18.71 19.5c-.83 1.24-1.71 2.45-3.05 2.47-1.34.03-1.77-.79-3.29-.79-1.53 0-2 .77-3.27.82-1.31.05-2.3-1.32-3.14-2.53C4.25 17 2.94 12.45 4.7 9.39c.87-1.52 2.43-2.48 4.12-2.51 1.28-.02 2.5.87 3.29.87.78 0 2.26-1.07 3.81-.91.65.03 2.47.26 3.64 1.98-.09.06-2.17 1.28-2.15 3.81.03 3.02 2.65 4.03 2.68 4.04-.03.07-.42 1.44-1.38 2.83M13 3.5c.73-.83 1.94-1.46 2.94-1.5.13 1.17-.34 2.35-1.04 3.19-.69.85-1.83 1.51-2.95 1.42-.15-1.15.41-2.35 1.05-3.11z"/></svg>

1. Ouvrez le **menu Pomme** et allez dans les **Réglages Système**.
2. Cliquez sur **Son** dans la barre latérale.
3. Allez dans l'onglet **Sortie**.
4. Sélectionnez le périphérique de sortie **Screenmate** — il apparaît sous le nom **S6-R (DisplayPort)** (l'autre écran apparaît sous le nom **S6-L**). Sur la capture d'écran, les *Haut-parleurs du MacBook* sont mis en évidence, mais vous devez choisir l'entrée **S6-R / Screenmate** pour entendre le son via votre Screenmate.
