## Configuration de l'affichage

<Tabs>
  <Tab title="Windows">
    **Vous souhaitez étendre votre espace de travail&nbsp;?**
    Ouvrez les **Paramètres d'affichage** et choisissez **«&nbsp;Étendre le Bureau à cet écran&nbsp;»**.

    Utilisez le bouton **Identifier** pour voir quel écran porte quel numéro. Vous pouvez ensuite faire glisser les écrans dans le bon ordre.

    <img src="/images/Screenmate%20-%20Infinity%20-%20Handleiding%20images/display-windows.png" alt="Paramètres d'affichage Windows" className="rounded-lg border border-gray-200" />

    <video controls className="rounded-lg border border-gray-200 dark:border-gray-700 my-4">
      <source src="https://firebasestorage.googleapis.com/v0/b/oase-documentation.firebasestorage.app/o/screenmate%2FoneCable%2Fwindows-Display-settings.mp4?alt=media&token=4b652dd6-b5bf-4f7b-b6a9-5f959ad5afe2" type="video/mp4" />
      Votre navigateur ne prend pas en charge la balise vidéo.
    </video>

    **Un écran est à l'envers&nbsp;?**
    Sélectionnez l'écran, allez dans **Orientation de l'affichage** et choisissez **«&nbsp;Paysage (inversé)&nbsp;»** pour corriger cela.

    **Vous souhaitez plus d'espace à l'écran&nbsp;?**
    Cliquez sur **Échelle** et réglez-la sur **150&nbsp;%** pour un texte et des éléments plus grands.

    <img src="/images/Screenmate%20-%20Infinity%20-%20Handleiding%20images/display-windows-scaling.png" alt="Paramètres Windows d'échelle, de résolution et d'orientation" className="rounded-lg border border-gray-200" />
  </Tab>
  <Tab title="macOS">
    1. Ouvrez les **Réglages Système**.
    2. Allez dans **Moniteurs**.
    3. Cliquez sur **Disposition** comme illustré sur l'image&nbsp;1.
    4. Faites glisser les écrans dans l'ordre souhaité comme illustré sur l'image&nbsp;2.

    <img src="/images/Screenmate%20-%20Infinity%20-%20Handleiding%20images/display-macos-displays.png" alt="Panneau Moniteurs de macOS avec le bouton Disposition" className="rounded-lg border border-gray-200" />

    <img src="/images/Screenmate%20-%20Infinity%20-%20Handleiding%20images/display-macos.png" alt="Disposition des écrans sous macOS" className="rounded-lg border border-gray-200" />

    <video controls className="rounded-lg border border-gray-200 dark:border-gray-700 my-4">

    **Un écran est à l'envers&nbsp;?**
    Sélectionnez l'écran, allez dans **Rotation** et choisissez **«&nbsp;Standard&nbsp;»** pour corriger cela.
  </Tab>
</Tabs>

## Réglages du son

<Tabs>
  <Tab title="Windows">
    - Cliquez sur l'icône du haut-parleur en bas à droite de la barre des tâches.

    <img src="/images/Screenmate%20-%20Infinity%20-%20Handleiding%20images/sound-windows-taskbar.png" alt="Icône de volume dans la barre des tâches Windows" className="rounded-lg border border-gray-200" />

    - À droite de la barre de volume, choisissez le périphérique de sortie souhaité.

    <img src="/images/Screenmate%20-%20Infinity%20-%20Handleiding%20images/sound-windows-flyout.png" alt="Volet de volume Windows" className="rounded-lg border border-gray-200" />

    - Vous pouvez régler le volume de chaque application séparément.
    - Tout en bas, vous trouverez un raccourci vers les paramètres de son complets.

    <img src="/images/Screenmate%20-%20Infinity%20-%20Handleiding%20images/sound-windows.png" alt="Paramètres de sortie audio Windows" className="rounded-lg border border-gray-200" />

    Sélectionnez le périphérique de sortie **Screenmate** — il apparaît sous le nom **S6-L (HD Audio Driver for Display Audio)** (l'autre écran apparaît sous le nom **S6-R**). Sur la capture d'écran, le **Speaker (Realtek(R) Audio)** mis en évidence est le haut-parleur intégré de votre ordinateur portable, et non le Screenmate — choisissez plutôt **S6-L**.
  </Tab>
  <Tab title="macOS">
    1. Ouvrez le menu Pomme et allez dans les **Réglages Système**.
    2. Cliquez sur **Son** dans la barre latérale.
    3. Allez dans l'onglet **Sortie**.
    4. Sélectionnez le périphérique de sortie **Screenmate** — il apparaît sous le nom **S6-R (DisplayPort)** (l'autre écran apparaît sous le nom **S6-L**). Sur la capture d'écran, les *Haut-parleurs du MacBook* sont mis en évidence, mais vous devez choisir l'entrée **S6-R / Screenmate** pour entendre le son via votre Screenmate.

    <img src="/images/Screenmate%20-%20Infinity%20-%20Handleiding%20images/sound-macos.png" alt="Réglages du son macOS" className="rounded-lg border border-gray-200" />
  </Tab>
</Tabs>
