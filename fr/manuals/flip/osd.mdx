## Utiliser le menu OSD

1. Appuyez sur le bouton **M** (Menu) pour ouvrir le menu OSD.
2. Utilisez les boutons **+** et **−** pour sélectionner le réglage souhaité.
3. Appuyez sur le bouton **M** (Menu) pour confirmer votre choix.
4. Maintenez le bouton **M** (Menu) enfoncé pour revenir à la page précédente.

<img src="/images/Screenmate%20-%20Flip%2015.6%20-%20Handleiding%20images/osd-backlight.png" alt="Menu OSD Rétroéclairage" className="rounded-lg border border-gray-200" />

## Rétroéclairage

- **Luminosité (BRIGHTNESS)&nbsp;:** réglable de 0 à 100.
- **Contraste (CONTRAST)&nbsp;:** réglable de 0 à 100.
- **Mode ECO (ECO)&nbsp;:** modes d'image préréglés pour différents usages (Standard, Game, Movie, Text, FPS, RTS, Energy Saving).
- **DCR (taux de contraste dynamique)&nbsp;:** choisissez ON ou OFF pour activer ou désactiver le contraste dynamique.
- **Netteté (SHARPNESS)&nbsp;:** réglable de 0 à 4.

## Image

<img src="/images/Screenmate%20-%20Flip%2015.6%20-%20Handleiding%20images/osd-image.png" alt="Menu OSD Image" className="rounded-lg border border-gray-200" />

- **Format d'image (ASPECT)&nbsp;:** basculez le format d'image entre 4:3 et WIDE.

## Couleur

<img src="/images/Screenmate%20-%20Flip%2015.6%20-%20Handleiding%20images/osd-color.png" alt="Menu OSD Couleur" className="rounded-lg border border-gray-200" />

- **Température de couleur (COLOR TEMP.)&nbsp;:** définissez manuellement les valeurs RVB ou choisissez un mode préréglé (Warm, Cool, User, Standard).
- **Rouge (RED)&nbsp;:** réglable de 0 à 100.
- **Vert (GREEN)&nbsp;:** réglable de 0 à 100.
- **Bleu (BLUE)&nbsp;:** réglable de 0 à 100.

## Réglages

<img src="/images/Screenmate%20-%20Flip%2015.6%20-%20Handleiding%20images/osd-set.png" alt="Menu OSD Réglages" className="rounded-lg border border-gray-200" />

- **Langue (LANGUAGE)&nbsp;:** choisissez la langue de l'OSD. Langues disponibles&nbsp;: anglais, français, allemand, chinois simplifié, italien, espagnol, portugais, turc, polonais, néerlandais, japonais, coréen.
- **Minuterie OSD (OSD TIMER)&nbsp;:** définissez le délai au bout duquel le menu des réglages se ferme automatiquement (10–60 secondes).
- **Transparence (TRANSPARENCY)&nbsp;:** réglez la transparence du menu des réglages.

## Réinitialisation

<img src="/images/Screenmate%20-%20Flip%2015.6%20-%20Handleiding%20images/osd-reset.png" alt="Menu OSD Réinitialisation" className="rounded-lg border border-gray-200" />

- **Réinitialisation (RESET)&nbsp;:** choisissez RESET pour rétablir tous les réglages à leurs valeurs d'usine.
- **Mode HDR (HDR MODE)&nbsp;:** activez le HDR (High Dynamic Range) si l'appareil est compatible. Modes disponibles&nbsp;: Off, Auto, 2084.

## Autres

<img src="/images/Screenmate%20-%20Flip%2015.6%20-%20Handleiding%20images/osd-other.png" alt="Menu OSD Autres" className="rounded-lg border border-gray-200" />

- **Source (SOURCE)&nbsp;:** choisissez parmi deux sources de signal&nbsp;: Type-C1 / Type-C2 et HDMI.
- **Lumière bleue faible (LOW BLUE LIGHT)&nbsp;:** réduit la quantité de lumière bleue émise par l'écran afin de limiter la fatigue oculaire.
