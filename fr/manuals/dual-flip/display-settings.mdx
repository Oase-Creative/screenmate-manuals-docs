## Configuration de l'affichage Windows

Faites un clic droit sur votre Bureau et choisissez **Paramètres d'affichage** pour ouvrir la configuration de l'affichage.

**Vous souhaitez étendre votre espace de travail&nbsp;?**

Allez dans Paramètres d'affichage et choisissez «&nbsp;Étendre le Bureau à cet écran&nbsp;». Utilisez le bouton «&nbsp;Identifier&nbsp;» pour voir quel écran porte quel numéro. Vous pouvez ensuite faire glisser facilement les écrans dans le bon ordre.

**Écran à l'envers&nbsp;?**

Sélectionnez l'écran concerné, allez dans «&nbsp;Orientation de l'affichage&nbsp;» et choisissez «&nbsp;Paysage (inversé)&nbsp;» pour corriger cela.

**Besoin d'une meilleure vue d'ensemble&nbsp;?**

Cliquez sur «&nbsp;Échelle&nbsp;» et réglez-la sur 150&nbsp;% pour un affichage plus grand du texte et des éléments.

## Configuration de l'affichage macOS

1. Ouvrez les Réglages Système.
2. Allez dans Moniteurs.
3. Cliquez sur Disposition.
4. Organisez les écrans dans l'ordre souhaité.

**Écran à l'envers&nbsp;?**

Sélectionnez l'écran concerné, allez dans «&nbsp;Rotation&nbsp;» et choisissez «&nbsp;Standard&nbsp;» pour corriger cela.
