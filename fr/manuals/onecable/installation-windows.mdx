### Windows 10 ou version ultérieure

Les pilotes nécessaires s'installent automatiquement dès que vous connectez le Screenmate via un câble USB-C ou USB-A.

Assurez-vous que votre ordinateur portable est connecté à Internet. Une fois l'installation terminée, il est recommandé de redémarrer votre ordinateur portable avant d'utiliser le Screenmate.

### Installation manuelle (si nécessaire)

Le pilote ne s'installe pas automatiquement&nbsp;?

Suivez ces étapes&nbsp;:

1. Ouvrez **Ce PC**, puis ouvrez le lecteur **DRIVERS (D:)** fourni (clé USB).
2. Ouvrez le dossier correspondant à votre version de Windows — pour Windows 10 ou 11, ouvrez le dossier **Win10&11** (les dossiers «&nbsp;mac OS&nbsp;» et «&nbsp;Win 7&8&nbsp;» sont également disponibles).
3. Double-cliquez sur le programme d'installation (**RacerDisplayDriver-2024.9.13-en**) et suivez les instructions à l'écran.
4. Redémarrez votre ordinateur portable après l'installation.
5. Connectez le Screenmate, il est maintenant prêt à l'emploi.
