## Réglages par écran

Le Screenmate Panorama propose des réglages indépendants pour chaque écran. Suivez les étapes ci-dessous pour configurer chacun d'eux.

### Ouvrir le menu OSD

- Appuyez brièvement sur le **bouton d'alimentation** pour ouvrir le menu OSD d'un écran.
- Appuyez de nouveau brièvement sur le bouton d'alimentation pour passer à l'écran suivant.
- Utilisez les boutons **+ / −** pour naviguer dans les menus.
- Appuyez sur le bouton **Confirmer / Quitter** pour sélectionner une option.
- Utilisez de nouveau les boutons **+ / −** pour régler les valeurs.

### Régler la luminosité

La luminosité se règle pour chaque écran séparément, de 0 à 100.

- Appuyez sur le bouton **Bas (−)** pour ouvrir le menu de luminosité.
- Appuyez sur le bouton **Quitter** pour fermer le menu.
- Appuyez de nouveau sur le bouton **Bas (−)** pour ouvrir le menu de luminosité de l'écran suivant.
- Réglez la luminosité à l'aide des boutons **+ / −**.

### Régler le volume

Le réglage du volume n'est disponible que sur l'écran gauche (moniteur DP).

- Appuyez sur le bouton **Haut (+)** pour ouvrir le menu de volume.
- Utilisez les boutons **+ / −** pour régler le volume de 0 à 100.

## Configuration de l'affichage (système d'exploitation)

Le Panorama pilote trois écrans indépendants, vous souhaiterez donc peut-être adapter la disposition du Bureau dans votre système d'exploitation.

### Windows

**Étendre votre espace de travail&nbsp;:** ouvrez les Paramètres d'affichage et choisissez **«&nbsp;Étendre le Bureau à cet écran&nbsp;»**. Utilisez le bouton **Identifier** pour voir quel écran porte quel numéro, puis faites-les glisser dans le bon ordre.

**Écran à l'envers&nbsp;?** Sélectionnez l'écran concerné, allez dans **Orientation de l'affichage** et choisissez **«&nbsp;Paysage (inversé)&nbsp;»** pour corriger cela.

**Besoin de plus d'espace&nbsp;?** Cliquez sur **Échelle** et réglez-la sur 150&nbsp;% pour agrandir le texte et les éléments d'interface.

### macOS

1. Ouvrez les **Réglages Système**.
2. Allez dans **Moniteurs**.
3. Cliquez sur **Disposition** comme illustré sur l'image&nbsp;1.
4. Faites glisser les écrans dans l'ordre souhaité comme illustré sur l'image&nbsp;2.
