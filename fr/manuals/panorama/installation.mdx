## Installation physique

Placez le Screenmate sur votre bureau avant de déplier les écrans.

1. Positionnez le Screenmate sur votre bureau comme illustré sur le schéma.

   <img src="/images/Screenmate%20-%20Panorama%20-%20Handleiding%20images/installation-step-1.png" alt="Placez le Screenmate plié sur votre bureau" className="rounded-lg border border-gray-200 dark:border-gray-700" />

2. Repliez les pieds de verrouillage vers l'intérieur.

   <img src="/images/Screenmate%20-%20Panorama%20-%20Handleiding%20images/installation-step-2.png" alt="Repliez les pieds de verrouillage vers l'intérieur" className="rounded-lg border border-gray-200 dark:border-gray-700" />

3. Saisissez les écrans et tirez-les vers le haut jusqu'à ce que les pieds s'engagent dans le verrou avant.

   <img src="/images/Screenmate%20-%20Panorama%20-%20Handleiding%20images/installation-step-3.png" alt="Tirez les écrans vers le haut jusqu'à ce que les pieds s'engagent dans le verrou avant" className="rounded-lg border border-gray-200 dark:border-gray-700" />

4. Faites pivoter les écrans vers le haut, puis dépliez-les jusqu'à l'angle de vision souhaité.

   <img src="/images/Screenmate%20-%20Panorama%20-%20Handleiding%20images/installation-step-4.png" alt="Dépliez les écrans jusqu'à l'angle de vision souhaité" className="rounded-lg border border-gray-200 dark:border-gray-700" />

<Note>
**Attention&nbsp;:** prenez garde à vos doigts lorsque vous repliez les écrans afin d'éviter tout pincement.
</Note>

Pour replier le Panorama, effectuez les étapes ci-dessus dans l'ordre inverse.

## Installer le pilote d'affichage

Avant de connecter le moniteur à votre PC ou à votre ordinateur portable pour la première fois, vous devez installer le pilote d'affichage approprié. Le Screenmate Panorama a besoin de ce pilote pour gérer plusieurs écrans via un seul câble.

Choisissez le logiciel qui correspond au système d'exploitation de votre ordinateur portable, téléchargez le fichier, décompressez l'archive, puis installez l'application en suivant les étapes affichées à l'écran.

Téléchargez le pilote depuis la page de téléchargement de Silicon Motion&nbsp;:  
[https://www.siliconmotion.com/downloads/index.html](https://www.siliconmotion.com/downloads/index.html)

## Options de connexion

### Option 1 — USB-C (câble unique)

Pour les ordinateurs portables équipés d'un port USB-C prenant en charge la sortie vidéo (DisplayPort Alt Mode).

1. Branchez l'adaptateur secteur 65&nbsp;W sur le port de charge USB-C du moniteur à l'aide du câble USB-C vers USB-C fourni.
2. Branchez le moniteur sur le port USB-C de votre ordinateur portable à l'aide d'un second câble USB-C vers USB-C.

<Info>
Utilisez le long câble blanc pour l'alimentation, et le court câble noir pour connecter le Panorama à votre ordinateur portable.
</Info>

<Note>
Le port USB-C d'un ordinateur portable ne fournit pas à lui seul une puissance suffisante pour faire fonctionner le Panorama à sa luminosité maximale. Branchez toujours l'adaptateur 65&nbsp;W pour un fonctionnement stable.
</Note>

<Note>
Le Panorama peut recharger votre ordinateur portable via USB-C grâce à la charge inversée (reverse charging). Brancher un chargeur séparé sur votre ordinateur portable alors que le Panorama l'alimente également peut provoquer un conflit d'alimentation.
</Note>

<img src="/images/Screenmate%20-%20Panorama%20-%20Handleiding%20images/connection-1-usb-c.png" alt="Schéma de connexion USB-C&nbsp;: ordinateur portable, Screenmate Panorama et adaptateur secteur" className="rounded-lg border border-gray-200 dark:border-gray-700" />

### Option 2 — USB-A + HDMI

Pour les ordinateurs portables dont le port USB-C ne prend pas en charge la sortie vidéo. Un câble HDMI supplémentaire est nécessaire pour piloter les trois écrans.

1. Branchez l'adaptateur secteur 65&nbsp;W sur le moniteur à l'aide du câble de charge USB-C vers USB-C.
2. Branchez le moniteur sur un port USB-A de votre ordinateur portable à l'aide d'un câble USB-A vers USB-C.
3. Enfin, reliez le port HDMI de votre ordinateur portable au moniteur à l'aide du câble Mini-HDMI vers HDMI. Sur le moniteur, branchez le câble HDMI sur le port HDMI situé à côté du câble d'alimentation blanc.
